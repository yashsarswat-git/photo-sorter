# Contributing

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. Backend: `cd backend && pip install -r requirements.txt && pytest`
3. Frontend: `cd frontend && npm install && npm run build`
4. Use [Conventional Commits](https://www.conventionalcommits.org) (`feat:`, `fix:`, `docs:`, `test:`).
5. Open a pull request describing what changed and why. CI must pass.
