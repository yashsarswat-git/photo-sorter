# Changelog

## [1.0.0] - 2026-10-02
### Added
- EXIF extraction (capture date, camera, GPS) with file-date fallback
- Folder layouts by year, month, location, camera or day
- Copy/move modes, duplicate detection and undo manifest
- FastAPI backend with scan, upload, preview, organize and settings endpoints
- React dashboard with stats, plan table, photo preview and dark/light theme
- Standalone no-install browser app (`standalone/PhotoSorter.html`)
- CI for backend tests and frontend build
